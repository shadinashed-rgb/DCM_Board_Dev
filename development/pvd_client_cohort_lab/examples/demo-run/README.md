# Synthetic PVD-first demonstration

All source rows and verification decisions in this directory are made-up fixtures. Actual target group labels/IDs are used only as the user-supplied seed configuration.

01_discovery shows candidate-only PVD discovery and missing other sources. 02_bridge_discovery shows additional IDs exposed by source group anchors. 03_entity_coverage shows the reviewed entity IDs unlocking Facilities/KYC. 04_reviewed_coverage adds explicit verified covenant relationship bridges. 05_signal_tests contains default unverified-business-rule signal outputs. Do not reuse the synthetic approval CSVs for real data. Counterparty catalog confirmation remains unresolved because the demonstration cannot verify a live table.
